# Mijn recepten

Recepten die ik vind op Pinterest en Instagram, gebundeld op één plek.
De site draait via GitHub Pages: https://michielpaesen.github.io/recepten/

## Een recept toevoegen

Elk recept is één bestand in de map `_recepten/`, bv. `_recepten/kip-curry.md`:

```markdown
---
title: Kip curry
bron: https://www.instagram.com/p/...
afbeelding: https://...        # optioneel
porties: 4                     # optioneel
tijd: 30 min                   # optioneel
tags: [kip, curry, hoofdgerecht]
---

## Ingrediënten

- ...

## Bereiding

1. ...
```

Het recept verschijnt automatisch op de site, met zoeken en filteren op tags.
